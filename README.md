## 环境

- Python 3.14
- 虚拟环境：`.venv/`

## 快速开始

```bash
git clone https://github.com/NagaSaki-SoyoLin/py_project01.git
cd py_project01
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```
